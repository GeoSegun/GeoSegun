## What I help with

- **API and developer documentation:** API references, integration guides, SDK walkthroughs, authentication guides, and troubleshooting.
- **Documentation engineering:** Documentation sites, information architecture, docs-as-code workflows, content migrations, and ongoing maintenance.
- **Product education:** Quickstarts, onboarding guides, feature walkthroughs, and tutorials that help developers reach their first working implementation.
- **Technical content:** Engineering articles, implementation tutorials, product explainers, and technical comparisons across developer tools, APIs, AI, cloud, and infrastructure.
